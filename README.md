# SIGPMAT

Sistema Integral de Gestión de Personal Médico y Asignación de Turnos Hospitalarios.

Proyecto académico de Análisis y Diseño de Software II — Universidad de El Salvador (ciclo II-2026).

Estado: backend Fastify v0.5 y esquema PostgreSQL implementados para desarrollo; frontend y módulos de turnos en construcción. **No apto para uso hospitalario real.**

El código y la documentación técnica se publicarán progresivamente en este repositorio.
